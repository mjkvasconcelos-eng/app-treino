# App Treino

Aplicativo mobile-first para organizar treinos de academia, registrar exercícios e acompanhar evolução.

## V1
- Treino do dia
- Planos de treino
- Exercícios por grupo muscular
- Registro preparado para séries/repetições/carga
- Progresso
- Perfil
- Estrutura preparada para evolução com Firebase

## Executar
```bash
npm install
npm run dev
```

## Próximas versões
Cronômetro de descanso, histórico persistente, autenticação, Firestore, biblioteca de exercícios com vídeos e planos por objetivo.
